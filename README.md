Exploratory Data Analysis (EDA) on Titanic Dataset# 🧠 Titanic EDA | Data Analyst Internship Task 5

## 📌 Objective
Perform Exploratory Data Analysis (EDA) on the Titanic dataset to extract key insights using visualization and statistics.

## 🔧 Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## 📊 Steps Followed
- Loaded and cleaned the data
- Handled missing values
- Performed univariate, bivariate, and multivariate analysis
- Created visualizations: histograms, boxplots, heatmaps, pairplots
- Encoded categorical variables
- Summarized key insights

## ✅ Key Insights
- Survival rate higher for females and 1st class passengers
- Fare is highly skewed; log transformation applied
- Age and Fare are positively correlated with survival
